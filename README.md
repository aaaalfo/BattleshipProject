# Игра "Морской бой"


### Основная информация

Я реализовал классическую консольную игру «Морской бой» для двух игроков.
Она написана на чистом питоне без использования сторонних библиотек.
Поддерживает пошаговый режим, цветной интерфейс, автоматическую очистку экрана и отображение попаданий.

### Требования

Python 3.8+

Консоль (терминал) с поддержкой ANSI цветов
(VS Code Terminal, macOS Terminal, Linux, Windows Terminal)

### Установка и запуск

`git clone https://github.com/aaaalfo/Battleship`
`cd <путь к репозиторию>`
`python3 (или python) main.py`

После запуска появится приветственное сообщение и приглашение ввести имена игроков.

### Правила игры

Каждый игрок по очереди размещает свой флот на поле 10×10.
После расстановки кораблей начинается пошаговая стрельба.
При попадании игрок получает дополнительный ход.
Корабль считается потопленным, когда все его палубы подбиты.
После потопления вокруг корабля автоматически отмечаются точки •, обозначающие зоны, куда нельзя стрелять.
Побеждает игрок, первым уничтоживший все корабли противника.
Всего флот состоит из одного 4-х палубного, двух 3-х палубных, трех 2-х палубных и четрех однопалубных кораблей

### Управление

Расстановка кораблей осуществялется следующим образом: <координата> <направление> <длина> (пример: A1 h 3 # горизонтальный корабль длиной 3)

Команды:

`show`        – показать текущее поле
`done`        – закончить, если все корабли расставлены
`exit` / `quit` – выйти из игры

Во время хода укажите координату, например B4

### Особенности проекта

- Полностью консольный интерфейс (ANSI цвета)
- Поддержка динамической очистки экрана
- Отображение состояния обоих полей
- Проверка корректности ввода
- Автоматическая установка точек вокруг потопленных кораблей
- Отдельные модули (Board, Player, Game, Ship, Utils)
- Соответствие стандарту PEP 8
